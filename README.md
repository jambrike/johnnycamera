#POLO OR T-SHIRT

an ai vision model for tensor flow trained using a simple 2+ class machine learning creator called teachable machine https://teachablemachine.withgoogle.com/

The Goal of this project i decided is "is it a t-shirt or a polo"
I decided this in 10 seconds doing a look around my room i trained it against 160ish photos of each and 4 different type of polos and t-shirts.
Seems to work for me but it also cant really tell the black polo from the black t-shirt but oh well.
